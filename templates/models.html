Machine Learning Models Reference

Definitions, intuitions, and mathematical formulas for 18 key algorithms.

Model Definition Formula / Intuition
Linear Regression Predicts a continuous outcome based on linear relationships. y = β₀ + β₁x + ε
Logistic Regression Classification algorithm using sigmoid function. P(y=1) = 1 / (1 + e^-(β₀+β₁x))
Decision Tree Splits data based on conditions to make predictions. Entropy = -Σ p log₂(p)
Random Forest Ensemble of decision trees to reduce overfitting. Prediction = Mode(Aggregated Trees)
K-Nearest Neighbors (KNN) Predicts based on the majority of nearest neighbors. d(x,y) = √Σ(xᵢ - yᵢ)²
Support Vector Machine Finds hyperplane that maximizes class margin. w·x + b = 0
Naive Bayes Probabilistic classifier assuming feature independence. P(C|X) ∝ P(X|C)·P(C)
AdaBoost Boosting technique combining weak learners. F(x)=Σ αᵢ hᵢ(x)
Gradient Boosting Boosting with gradient descent optimization. y = Σ fₘ(x), fₘ fits residuals
XGBoost Optimized gradient boosting with regularization. Obj = Loss + Ω(Complexity)
LightGBM Efficient gradient boosting using leaf-wise splits. Leaf-wise Growth
CatBoost Boosting optimized for categorical features. Ordered Boosting
K-Means Clustering Partitions data into k clusters based on distance. μₖ = (Σ xᵢ)/nₖ
Hierarchical Clustering Builds a hierarchy of clusters using linkage. d(A,B) = min/max/avg distance
PCA Reduces dimensionality by maximizing variance. Z = XW, W = eigenvectors
Neural Networks Layered structure of neurons to learn patterns. a = σ(Wx + b)
CNN Specialized for image recognition with convolution filters. (f * g)(t) = ∫ f(τ)g(t-τ)dτ
RNN Sequential models with memory of past inputs. hₜ = f(Wxₜ + Uhₜ₋₁ + b)
