About the Project

A Machine Learning powered system that predicts agricultural water usage using real-world environmental features and Nash Equilibrium strategies.

Project Overview

This project aims to address the growing challenge of agricultural water overuse in India. By combining Machine Learning models with principles of Nash Equilibrium, the system predicts optimal irrigation and water distribution requirements.

The model analyzes factors such as soil moisture, rainfall, groundwater levels, crop water requirements, and temperature to determine whether water usage is optimal, underused, or overused.

Key Components

Machine Learning Models

18+ supervised learning models are used for prediction and performance comparison.

Nash Equilibrium Logic

Ensures fair and optimal distribution between multiple competing farms.

Data Preprocessing

Includes label encoding, missing value handling, and auto-calculation of Nash Payoff.

Interactive Predictions

Users can input real farming data through a simple form to get personalized predictions.
